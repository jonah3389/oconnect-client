# 目标与验收

## 用户目标

每台电脑使用自己的身份，首次由手机授权后，通过同一局域网增量采集 OPPO 手表录音。电脑无需安装官方互联客户端，日常无需记住手机 IP；手机地址变化后，继续使用已有配对关系同步。

## 使用过程

1. 在电脑本机生成身份，指定手机当时的地址完成首次配对，并在手机上确认。
2. 日常运行 list、sync 或 watch 时省略 host；只有一台已配对手机时自动选择，多台时指定 peer。
3. 先尝试上次认证成功的地址；失败后发原生组播 QUERY，再用受限子网单播 QUERY 兜底。
4. 发现包按设备 ID 筛选候选，用原配对密钥完成认证后才更新地址缓存并读取录音。
5. 下载新增录音，校验完整性后保存；已下载且本地内容校验一致的录音跳过。手机暂时离线时保留配对关系，watch 在下一轮重新尝试。

## 范围

生成本机身份、首次配对、地址自动发现、查询手表录音、完整下载、内容哈希检查点、持续轮询与失败重试。手机数据只读，保留手机源文件与本地同名异内容文件。

自动发现只使用当前 LAN 的 IPv4 网卡；默认排除常见 VPN、隧道、虚拟和回环网卡，支持手动限定网卡。子网兜底每个网段总地址数最多 256 个，只向原生发现端口发送查询；超过范围跳过，不扫描更大网络。

## 成功标准

- 安装后的 CLI 可从项目目录外运行，不依赖源码相对路径或官方账号数据库。
- 新身份具有不同设备 ID 和密钥，首次操作由手机同意；日常换地址不重新触发配对，不重写原身份文件。
- 配对授权按设备 ID 选择，地址单独缓存；未知设备不自动配对，认证失败的候选不覆盖缓存。
- 失效地址能够经组播恢复；组播无应答时能够使用受限子网查询；有效缓存直接连接，不重复发现。
- 音频经过 Range 范围、大小和完整下载验证后才原子落盘；第二轮跳过已验证的未变文件。
- 默认测试离线，实机验证显式开启；私密配置、运行状态和音频不进入公开 Git 或发行包。

## 不包含

官方客户端的其他功能、录音转写、云端账号签发、后台调度部署。持续轮询仅在使用者启动的进程中运行。长时间休眠、不同平台、手机重启或系统版本变化的支持情况，以[实际验收记录](working.md)为准。
