# 目标与验收

## 用户目标

每台电脑使用自己的身份，首次由手机授权后，通过 Wi-Fi 在锁屏场景下增量采集手表录音，电脑不安装官方互联客户端。

## 范围

生成本机身份、首次配对、查询手表录音、完整下载、哈希去重、持续轮询与连接失败后重试。手机数据只读；保留手机源文件与本地同名异内容文件。

## 成功标准

- 安装后的 CLI 可从项目目录外运行，不依赖源码相对路径或官方账号数据库。
- 新身份具有不同设备 ID 和密钥，首次操作由手机同意；日常同步不重新触发配对。
- 音频经过范围、大小和完整下载验证后才原子落盘；第二轮跳过未变文件。
- 默认测试离线，私密配置与音频不进入 Git 或发行包。

## 不包含

官方客户端的其他功能、手机录音转写、云端账号签发、后台调度部署。不同平台与手机版本的支持情况以实际验收为准。
