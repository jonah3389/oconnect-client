# 工作记录

## Changelog

### 2026-10-31（0.2.0）

- 日常 list/sync/watch 支持省略host：先用认证地址缓存，失败后原生组播QUERY，最后受限子网原生单播查询。组播3轮、间隔200ms；每个兜底网段总地址数最多256、查询间隔10ms。排除常见VPN/虚拟网卡，支持指定interface与关闭子网兜底。
- 配对密钥按设备ID选择；单台自动选择，多台必须指定peer。旧身份文件无需迁移，旧host仅为无缓存时的连接提示；认证后更新独立地址缓存，失败不更新，不自动pair。首次pair重用密钥同样要求显式指定peer，不再按host查找旧授权。
- QUERY在临时UDP端口接收ANNOUNCE，以数据包来源IP定位候选，再进行原OAFP服务端MAC验证；不使用VIRTUAL_IP或发现包中的任意端口改变文件连接目的。进度走stderr，list的stdout保持JSON。
- 新增回归：IP变化不改身份、多个peer选择、缓存/组播/子网顺序、认证失败不污染缓存、业务失败不重复操作、真实loopback UDP回复端口、未知ID/异常包过滤、网段与网卡限制。37项离线测试及10项子测试通过，2项实机测试默认跳过。
- 显式实机2项通过：旧地址缓存失败后组播找到已配对手机；隔离目录下载最小录音并校验长度/SHA-256，再次命中缓存跳过重复下载；仅注入组播无应答时，真实子网QUERY、认证与目录读取成功。身份文件逐字节不变。旧实机下载测试改用filePath哈希命名，兼容无fileId目录接口。
- 本机正式投放目录的免host增量同步通过：发现5条、下载0条、跳过5条。完整地址与原始实机证据仅保存在被忽略的private目录。
- Ruff检查、格式、源码隐私检查、sdist/wheel构建通过。工作区技能入口、私有调用配置与音频接入说明已更新；未增加无线下载定时任务，未推送远端。
- 实机覆盖的是失效缓存注入与组播无应答注入；没有主动修改手机DHCP租约，过夜休眠、真实换网、多手机、多实体电脑与Windows仍待独立验收。

## Lessons Learned

- 手机反向连接完成后，不能再创建同一身份的第二条默认控制连接。
- 单一文件 API 成功不能替代首次手机配对 UI 的确认。
- 通道密钥与连接方向相关，迁移时必须保留角色选择。
- 项目路径不应作为运行状态默认位置，安装包需要从任意目录运行。
